# Blur Social Automation

## Setup

### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
Access at: http://localhost:3000

### 2. Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```
API running at: http://localhost:8000

## Features
- Create posts (Text, Image, Video)
- Save posts locally to SQLite database
- Media saved to `backend/media` folder
